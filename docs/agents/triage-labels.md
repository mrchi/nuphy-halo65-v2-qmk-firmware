# Triage Labels

本项目使用默认 triage 标签。Local Markdown issue 的 `Status:` 行记录对应标签。

| 角色 | 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 需求完整，可交由 Agent 实现 |
| ready-for-human | ready-for-human | 需要人工实现 |
| wontfix | wontfix | 不予处理 |

技能提及 triage 角色时，使用上表对应的标签。
