# 出厂默认由 EEPROM 标志位一次性写入

---
status: accepted
---

出厂默认灯光（环灯关闭、定位灯橙色 25% 亮度）必须在一台 EEPROM 里已写过旧标志位的设备上生效一次，但又不能每次上电都覆盖用户在 VIA 里的调节。做法是把 `user_config.default_brightness_flag` 从 `0xA5` 改为 `0xA6` 作为触发信号：固件检测到标志位不匹配时调用 `m_apply_factory_defaults()`，集中写入全部出厂默认并更新标志位，此后不再覆盖。

## Considered Options

- **只改代码里的默认值，不动标志位**：已在用的设备看不到任何变化，等于没改。
- **每次上电强制覆盖**：用户在 VIA 里的调整会被吃掉。

## Consequences

- **标志位是单向的。** 以后再改出厂默认值必须再次 bump（`0xA6` → `0xA7`），否则已刷过本固件的设备拿不到新值。bump 会连带强制重置那些已经手动调好灯光的设备，只在确实需要时做。
- `m_apply_factory_defaults()` 同时被 `m_londing_eeprom_data()`（首次上电与标志位不匹配时）和 `device_reset_init()`（设备重置）调用，保证长按恢复出厂的结果与首次上电一致。这两处原本各写一份数值，目前碰巧相等；一旦只改其中一处（例如只把首启亮度改成 25%），设备重置就会把亮度弹回旧值、并把环灯重新打开，而代码里看不出两者是同一个约定。
